할인코드 선택과 오류

클룩 할인코드를 입력했는데 적용되지 않으면 어떻게 하나요?

적용 실패 안내에서 제한 항목을 먼저 확인하세요. 문자열의 앞뒤 공백을 지우고 선택 옵션이 대상 상품인지 확인하세요. 계정 사용 이력과 행사 잔여 수량도 적용에 영향을 줍니다.

신한 Visa 할인코드의 숫자 25는 모두 25%를 뜻하나요?

모두 25%를 뜻하지 않습니다. 기타 상품용 할인코드는 문자열에 25가 들어가지만 실제 할인율은 15%이므로 혜택 설명을 기준으로 선택하세요.

클룩 원화 최소 결제액에 맞추면 USD 할인도 적용되나요?

환산 원화 금액만으로 적용을 보장할 수 없습니다. USD 결제 화면의 상품 금액이 실제 최소 기준을 충족하는지 확인하세요.

클룩 할인코드는 앱에서만 사용할 수 있나요?

제공된 여섯 혜택에는 앱 전용 조건이 명시되어 있지 않습니다. 접속한 프로모션의 기기 제한 안내가 있다면 해당 안내를 따르세요.

예약 구성과 사용 횟수

가족 티켓을 나누어 결제하면 할인이 더 커지나요?

분할 결제가 항상 유리하지는 않습니다. 계정당 사용 횟수가 제한되어 있고 각각 최소 결제를 충족해야 하므로 한 예약의 할인액과 나눈 예약의 총 할인액을 먼저 비교하세요.

클룩 할인코드 사용 횟수는 결제 카드마다 따로 생기나요?

안내된 횟수는 계정 기준입니다. 카드를 바꾸면 사용 횟수가 새로 생긴다고 계산하지 마세요.

입장권과 eSIM을 합쳐 최소 결제를 채워도 되나요?

서로 다른 상품 분류의 합산 적용은 보장할 수 없습니다. 예약 단위와 할인 대상 금액이 결제 화면에서 어떻게 계산되는지 확인하세요.

지금 가장 많이 깎이는 할인코드는 무엇인가요?

같은 요금제에 적용된다면 높은 할인율이 유리하지만, 미확정 혜택은 예산에서 제외하세요.

할인율 차이를 실제 지출로 해석하세요

25%와 20%의 차이는 1,000원입니다.동일한 20,000원 상품을 비교한 결과이며 실제 판매가를 뜻하지 않습니다. 공개 할인쿠폰은 등록 가능 여부와 표시 할인율이 확인되어야 비교 후보에 넣을 수 있습니다.

한도 도달 금액은 계산할 수 없습니다.최대 할인액이 공개되지 않았으므로 고액 상품에도 같은 비율이 끝까지 적용된다고 단정하지 않습니다. 결제 화면의 차감액으로 최종 판단하세요.

  • 상품 두 개의 결제를 구분하세요.한 장을 여러 상품에 나눠 적용할 수 없으므로 각 상품의 쿠폰 선택 상태를 따로 확인하세요.

  • 요금제 조건을 고정하세요.같은 국가라도 사용 일수와 데이터 용량이 다르면 할인 후 가격만으로 우열을 판단하기 어렵습니다.

할인코드는 어디에 넣나요?

쿠폰 등록과 결제 시 사용 선택을 모두 완료해야 차감 여부를 확인할 수 있습니다.

계정에 등록한 뒤 결제에서 선택하세요

  1. 01로그인

    구매할 계정으로 접속하세요

    유심사 홈페이지에서 로그인하고 하단 프로필을 선택하세요. 추천인 혜택은 가입 단계의 입력 항목과 구분하세요.

  2. 02등록

    쿠폰 번호 입력란을 사용하세요

    프로필의 쿠폰 메뉴를 열고 상단 쿠폰 번호 칸에 할인코드 전체를 입력한 뒤 등록을 선택하세요. 문자 앞뒤의 공백이 들어가지 않도록 확인하세요.

  3. 03상품

    국가·일수·용량을 정하세요

    eSIM과 실물 유심 중 필요한 형태를 선택하고 상품 한 개 기준으로 결제 조건을 살펴보세요.

  4. 04적용

    결제 페이지에서 사용하기를 선택하세요

    쿠폰 선택에서 사용할 쿠폰을 지정한 뒤 사용하기를 누르세요. 보유 적립금의 사용 가능 금액까지 반영하고 실제 결제액을 확인하세요.

  • 입력값을 먼저 확인하세요.숫자와 영문을 원문과 대조하고 복사 과정에서 공백이 붙었는지 살펴보세요.

구매 금액과 사용 조건

유심사 할인쿠폰 두 장을 함께 사용할 수 있나요?

쿠폰끼리는 중복 적용할 수 없습니다.여러 쿠폰이 등록되어 있어도 이번 상품에 사용할 한 장을 선택하세요. 적립금과의 병용은 개별 혜택 조건을 확인하세요.

최소 결제 금액이 없다고 생각해도 되나요?

표기 없음은 제한 없음과 다릅니다.구매하려는 상품에 쿠폰이 선택되는지와 실제 할인액을 확인한 뒤 결제하세요.

적립금 1,000원은 나눠 쓸 수 있나요?

1,000원 단위로 사용합니다.잔액이 정확히 1,000원이라면 사용 시 전액이 소진되므로 다음 상품에도 같은 금액이 남는 것으로 계산하지 마세요.
